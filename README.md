# TaskFlow

**TaskFlow** — это backend-сервис для управления проектами и задачами, который я сделал как pet-project, чтобы отработать проектирование API, ролевую модель доступа, JWT-аутентификацию, работу с PostgreSQL и асинхронный стек на FastAPI

Проект моделирует рабочий сценарий командной работы: пользователь регистрируется, создает проект, добавляет участников с разными ролями, ставит задачи, назначает исполнителей, фильтрует задачи и отслеживает историю изменений

## Зачем этот проект

Я хотел собрать сервис с логикой, близкой к реальным рабочим задачам:
- авторизация и защита приватных данных;
- разграничение прав внутри проекта;
- управление сущностями, связанными между собой;
- история изменений для важных полей задачи;
- запуск в Docker-окружении;

## Что умеет сервис

### Пользователи
- регистрация нового пользователя;
- логин по email и паролю;
- получение данных текущего пользователя по JWT-токену;

### Проекты
- создание проекта;
- просмотр списка проектов, в которых состоит пользователь;
- просмотр деталей конкретного проекта;
- обновление проекта;
- удаление проекта;
- добавление участников в проект;
- просмотр списка участников проекта;

### Роли и доступ
Внутри проекта реализована ролевая модель:
- **OWNER** — владелец проекта;
- **ADMIN** — администратор;
- **MEMBER** — участник с правом работать с задачами;
- **VIEWER** — наблюдатель только с чтением;

### Задачи
- создание задачи внутри проекта;
- назначение исполнителя;
- получение списка задач проекта;
- фильтрация задач по `status`, `priority` и поиску по названию;
- пагинация списка задач;
- просмотр конкретной задачи;
- обновление задачи;
- удаление задачи;
- просмотр истории изменений задачи;

### История изменений
При изменении важных полей задачи сервис сохраняет запись в `TaskHistory`. Это позволяет отслеживать, **кто**, **что** и **когда** изменил

## Стек

- **Python 3.13**
- **FastAPI**
- **SQLAlchemy 2.0 (async)**
- **PostgreSQL**
- **Alembic**
- **Pydantic 2**
- **Docker / Docker Compose**
- **Poetry**
